## 🚀 주요 기능

- **예술가/프로젝트 탐색** - 카테고리 필터 및 검색 기능
- **AI 기반 매칭** - 예술가와 프로젝트를 AI가 자동 매칭
- **포트폴리오 관리** - 예술가 포트폴리오 등록 및 관리
- **프로젝트 지원 관리** - 기업용 지원자 현황 대시보드

<br>

## 🛠 기술 스택

### Frontend
| 구분 | 기술 |
|------|------|
| Framework | Next.js 15, React 19 |
| Language | TypeScript |
| 상태 관리 | React Query, Zustand |
| 스타일링 | TailwindCSS, shadcn/ui |
| 폼 관리 | React Hook Form, Zod |
| 코드 품질 | Husky, ESLint, Prettier, lint-staged |
